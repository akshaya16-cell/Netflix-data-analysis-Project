# Netflix EDA Project

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Titles dataset using Python. The objective is to understand Netflix's content library by analyzing movies, TV shows, genres, ratings, countries, directors, actors, and release trends.

## Dataset

- Source: Kaggle
- File: netflix_titles.csv

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Workflow

- Data Loading
- Data Cleaning
- Missing Value Handling
- Duplicate Check
- Exploratory Data Analysis
- Data Visualization
- Business Insights

## Analysis Performed

- Movies vs TV Shows
- Release Year Trend
- Top 10 Countries
- Rating Distribution
- Top Genres
- Top Directors
- Top Actors
- Movie Duration Analysis
- TV Show Seasons Analysis

## Key Business Insights

- Netflix contains more Movies than TV Shows.
- Content production increased significantly after 2015.
- The United States contributes the highest number of titles.
- TV-MA is the most common content rating.
- International Movies and Dramas are among the most common genres.
- Director information contains the highest number of missing values.
