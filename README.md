# 🎬 Netflix Data Analysis Project

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on the Netflix Titles dataset using Python. The objective is to analyze Netflix's content library, identify trends, and generate business insights through data cleaning, visualization, and statistical analysis.

---

## 📂 Dataset

* **Source:** Kaggle
* **Dataset:** `netflix_titles.csv`

---

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## 📋 Project Workflow

1. Data Loading
2. Data Cleaning
3. Handling Missing Values
4. Removing Duplicate Records
5. Data Type Conversion
6. Exploratory Data Analysis (EDA)
7. Data Visualization
8. Business Insights

---

## 📊 Analysis Performed

* Movies vs TV Shows Distribution
* Netflix Content Growth Over the Years
* Top 10 Countries with Most Content
* Content Rating Distribution
* Top Genres on Netflix
* Top Directors
* Top Actors
* Movie Duration Analysis
* TV Show Seasons Analysis
* Missing Value Analysis

---

## 📈 Key Business Insights

* Netflix contains significantly more **Movies** than **TV Shows**.
* Content production increased rapidly after **2015**.
* The **United States** contributes the highest number of titles.
* **TV-MA** is the most common content rating.
* **International Movies** and **Dramas** are among the most popular genres.
* The **Director** column contains the highest number of missing values.
